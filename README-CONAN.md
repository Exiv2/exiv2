# Building Exiv2 and dependencies with Conan

[Conan](https://conan.io/) is a portable package manager for C/C++ libraries.
It can provide the dependencies needed to build Exiv2 without installing them
as system packages. Exiv2 uses Conan 2.

You also need CMake. See <https://cmake.org/download/>.

## Install Conan

Install Conan with pip:

```bash
python -m pip install conan
```

For other installation methods, see the [Conan installation
documentation](https://docs.conan.io/2/installation.html).

Before the first build, detect a default profile for your compiler:

```bash
conan profile detect --force
```

## Build Exiv2

From the root of the Exiv2 source tree, install the dependencies into the
build directory, configure, build, and test:

```bash
conan install . -o webready=True --build missing --output-folder=build -s build_type=Release
cmake -S . -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build
ctest --test-dir build
```

`--output-folder=build` writes the files generated by Conan's `CMakeDeps`
generator where Exiv2's CMake configuration can find them. The `webready`
option enables the dependencies required for HTTP, HTTPS, and FTP support.

To create a Debug build, use a separate build directory and select the Debug
build type:

```bash
conan install . -o webready=True --build missing --output-folder=build-debug -s build_type=Debug
cmake -S . -B build-debug -DCMAKE_BUILD_TYPE=Debug
cmake --build build-debug
ctest --test-dir build-debug
```

## Visual Studio

Open a Developer Command Prompt for Visual Studio, then run the same commands.
For a 64-bit Release build with Visual Studio:

```bat
conan install . -o webready=True --build missing --output-folder=build -s build_type=Release -s compiler=msvc -s arch=x86_64
cmake -S . -B build -G "Visual Studio 17 2022" -A x64
cmake --build build --config Release
ctest --test-dir build -C Release
```

For a 32-bit build, use `-A Win32` and `-s arch=x86`. To build with a
different Visual Studio version, select its corresponding CMake generator.
